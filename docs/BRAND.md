# PaSiBudget logo

Created with the built-in image generation tool on 25 September 2026.

Final asset: `public/brand/pasibudget-logo.png` (1254 × 1254, opaque RGB PNG).

The gold rice stalk represents the harvest, while the two ivory lines suggest rice terraces and a simple budget ledger. A forest-green backing gives the mark a consistent appearance in both themes. The application rounds its corners in CSS. This logo is separate from the animated opening-grain theme control.

The same local asset supplies the sidebar, welcome screen, footer, loading/error states, favicon, Apple touch icon, and PWA icon. The PWA caches it for offline use. Browsers resize the high-resolution icon to the required display dimensions. Existing installed shortcuts may retain an older icon until the browser refreshes their metadata or the app is reinstalled.

## Generation direction

An original, minimal rice-and-coin emblem for an offline Filipino rice-farm budget planner: forest green, harvest gold, and ivory; a curved rice stalk with five separate grains above two terrace/ledger lines; no lettering. The transparent draft was refined into a fully opaque app icon so it renders reliably on all backgrounds.

Whole image is an opaque flat green square with the gold and ivory emblem centered at 70 percent size so there is generous balanced green padding.
